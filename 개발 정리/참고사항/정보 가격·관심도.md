# 정보 가격 단계제와 관심도 공개

작성: 2026-11-21, 도강현(정보 구매·코인 담당). 게임 틀(6턴, 랜덤 1일 정보, 실시간 매매)은 그대로 두고 정보 단계의 선택만 늘린 작은 수정이다.

## 1. 같은 기업 정보 가격 단계제

한 턴 안에서 **같은 기업**의 랜덤 1일 정보를 살수록 가격이 오른다.

| 그 기업에서 이번 턴에 산 날짜 | 다음 1일 가격 |
| --- | --- |
| 0~2일 | 1코인 |
| 3~5일 | 2코인 |
| 6일 이상 | 3코인 |

- 다른 기업은 다시 1코인부터 시작한다. 플레이어마다 따로 계산하고, 다음 턴에는 초기화된다.
- 공용 공개 5일과 증강 정보는 개수에 넣지 않는다. 코인으로 산 날짜만 센다.
- 15코인 기준: 한 기업만 깊게 보면 8일(공용 5일 포함 13/25일), 5개 기업에 넓게 보면 15일.
- **목적:** "한 기업 패턴을 확실히 읽을지, 여러 기업을 넓게 볼지"를 고르게 한다. 같은 기업을 반복 구매해 거의 전부 보이던 문제(11/13 회의)를 줄인다.
- 버튼은 `랜덤 1일 · N코인`으로 다음 가격을 보여 준다. 코인이 모자라면 버튼이 꺼진다.

## 2. 기업별 관심도(익명) 공개

정보 탐색 중 각 기업 정보 창 아래 상태 줄에 `이번 턴 전체 구매 N일`을 보여 준다.

- 4명이 이번 턴에 그 기업에서 **코인으로 산 날짜 수의 합계**다. 누가 샀는지는 보내지 않는다.
- 실시간 매매에서 기업당 20주를 4명이 나눠 가지므로, 관심이 몰린 기업은 물량 경쟁이 생길 수 있다는 신호가 된다. 일부러 다른 기업 정보를 사서 관심을 흩뜨리는 심리전도 가능하다(단, 단계제 때문에 비용이 든다).
- 서버: `PublicState.informationInterest` (`CompanyInterest { companyId, purchasedDays }`), `IWindowInformationService.GetInformationInterest`.
